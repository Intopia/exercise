Testing document title: empty title

The <title> element is present in <head>, but has no text content. Distinct from the missing-title case, the element exists, it's just empty, and browsers/AT may treat that differently from the element being absent entirely.

Expected result: browsers typically fall back to showing the page's URL or a blank tab. Whether assistive technology announces an empty string, falls back to the URL, or announces nothing at all on page load is genuinely worth confirming directly, this is exactly the kind of case that varies by implementation.

HTML markup 
<head>
  <title></title>
</head>
