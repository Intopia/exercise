Testing errors on checkbox groups

Error messages for a group of checkboxes need to be programmatically associated with the group, not just placed near it. Every example is pre-set in the markup, so no JavaScript is needed.

Simplest approach: link the error to the group with aria-describedby. See the recommended examples.

1. Text with no association

Example 1.1: Error, not linked

A fieldset with the error in a paragraph inside it.

Which pets do you have?

Error: Choose at least one pet.

Poor practice: Nothing associates the error with the group, so assistive technology users may not hear it.

HTML markup 
<fieldset>
  <legend>Which pets do you have?</legend>
  <p class="error">Error: Choose at least one pet.</p>
  <div>
    <input type="checkbox" id="c1-dog" name="c1" value="dog">
    <label for="c1-dog">Dog</label>
  </div>
  <div>
    <input type="checkbox" id="c1-cat" name="c1" value="cat">
    <label for="c1-cat">Cat</label>
  </div>
  <div>
    <input type="checkbox" id="c1-rabbit" name="c1" value="rabbit">
    <label for="c1-rabbit">Rabbit</label>
  </div>
</fieldset>

2. Error as text in the group's name

Example 2.1: fieldset

The error is added to the group's name.

Which pets do you have? Error: Choose at least one pet.

Poor practice: The error is part of the group's accessible name, so it is announced when users enter the group. But it makes the name longer and changes it whenever there is an error, and it does not expose an invalid state. Prefer aria-describedby.

HTML markup 
<fieldset>
  <legend>Which pets do you have? <span class="error">Error: Choose at least one pet.</span></legend>
  <div>
    <input type="checkbox" id="c2-dog" name="c2" value="dog">
    <label for="c2-dog">Dog</label>
  </div>
  <div>
    <input type="checkbox" id="c2-cat" name="c2" value="cat">
    <label for="c2-cat">Cat</label>
  </div>
  <div>
    <input type="checkbox" id="c2-rabbit" name="c2" value="rabbit">
    <label for="c2-rabbit">Rabbit</label>
  </div>
</fieldset>

Example 2.2: div with role="group"

The error is added to the group's name.

3. aria-describedby on the checkboxes

Example 3.1: aria-describedby on each checkbox

Every checkbox has aria-describedby pointing to the error.

Which pets do you have?

Error: Choose at least one pet.

Poor practice: The error is repeated on every checkbox, and it is not associated with the group itself.

HTML markup 
<fieldset>
  <legend>Which pets do you have?</legend>
  <p class="error" id="c4-error">Error: Choose at least one pet.</p>
  <div>
    <input type="checkbox" id="c4-dog" name="c4" value="dog" aria-describedby="c4-error">
    <label for="c4-dog">Dog</label>
  </div>
  <div>
    <input type="checkbox" id="c4-cat" name="c4" value="cat" aria-describedby="c4-error">
    <label for="c4-cat">Cat</label>
  </div>
  <div>
    <input type="checkbox" id="c4-rabbit" name="c4" value="rabbit" aria-describedby="c4-error">
    <label for="c4-rabbit">Rabbit</label>
  </div>
</fieldset>

Example 3.2: aria-describedby on one checkbox only

Only the first checkbox has aria-describedby pointing to the error.

Which pets do you have?

Error: Choose at least one pet.

Poor practice: Only that checkbox has the error description, so users may think it applies to that checkbox only, not the group.

HTML markup 
<fieldset>
  <legend>Which pets do you have?</legend>
  <p class="error" id="c5-error">Error: Choose at least one pet.</p>
  <div>
    <input type="checkbox" id="c5-dog" name="c5" value="dog" aria-describedby="c5-error">
    <label for="c5-dog">Dog</label>
  </div>
  <div>
    <input type="checkbox" id="c5-cat" name="c5" value="cat">
    <label for="c5-cat">Cat</label>
  </div>
  <div>
    <input type="checkbox" id="c5-rabbit" name="c5" value="rabbit">
    <label for="c5-rabbit">Rabbit</label>
  </div>
</fieldset>

4. Error linked to the group

Example 4.1: fieldset

The group has aria-describedby pointing to the error.

Which pets do you have?

Error: Choose at least one pet.

Recommended: The error is associated with the group with aria-describedby, so assistive technology can announce it as the group's description. It does not expose an invalid state.

HTML markup 
<fieldset aria-describedby="c6-error">
  <legend>Which pets do you have?</legend>
  <p class="error" id="c6-error">Error: Choose at least one pet.</p>
  <div>
    <input type="checkbox" id="c6-dog" name="c6" value="dog">
    <label for="c6-dog">Dog</label>
  </div>
  <div>
    <input type="checkbox" id="c6-cat" name="c6" value="cat">
    <label for="c6-cat">Cat</label>
  </div>
  <div>
    <input type="checkbox" id="c6-rabbit" name="c6" value="rabbit">
    <label for="c6-rabbit">Rabbit</label>
  </div>
</fieldset>

Example 4.2: div with role="group"

The group has aria-describedby pointing to the error.

Which pets do you have?

Error: Choose at least one pet.

Recommended: The error is associated with the group with aria-describedby, so assistive technology can announce it as the group's description. It does not expose an invalid state.

<div role="group" aria-labelledby="c7-label" aria-describedby="c7-error">

  <div>

  </div>
  <div>
    <input type="checkbox" id="c7-cat" name="c7" value="cat">

</div>

Using hints and errors together

A group can have both a hint and an error. Hints and errors use the same method, so list both IDs in one aria-describedby, separated by a space. See Testing hints on checkbox groups.

<fieldset aria-describedby="pets-hint pets-error">
  <legend>Which pets do you have?</legend>
  <p id="pets-hint">Choose all that apply.</p>
  <p id="pets-error">Error: Choose at least one pet.</p>
  <!-- checkbox inputs and labels -->
</fieldset>
