Testing VoiceOver groups

VoiceOver may treat some parts of a page as groups. A group is a container that VoiceOver moves past as one item until you choose to go inside it. Whether something is treated as a group can depend on your browser and VoiceOver settings.

Move through each example and listen for whether VoiceOver treats it as one item. If it does, try entering and leaving it.

  • To enter a group: press VO + Shift + Down Arrow (interact).
  • To move through items inside a group: press VO + Right Arrow or VO + Left Arrow.
  • To leave a group: press VO + Shift + Up Arrow (stop interacting).

1. Table

VoiceOver treats a table as a group. Interact with it to move between cells.

Example 1.1: Data table

A table with a caption, column headers and row headers.

Course schedule

2. Scrollable region

A region that scrolls, and can take keyboard focus, may be treated as a group.

Example 2.1: Code block

A pre that scrolls. It is a focusable region with a name, so keyboard users can scroll it.

function countFailures(results) {
    var total = 0;
    for (var i = 0; i < results.length; i++) {
      if (results[i].impact === 'critical') {
        total = total + 1;
      }
    }
    return total;
  }

  function showSummary(total) {
    var message = 'Critical failures: ' + total;
    console.log(message);
    return message;
  }

  var results = runChecks();
  showSummary(countFailures(results));
HTML markup 
<div class="scroll" role="region" aria-label="Example code" tabindex="0">
<pre><code>function countFailures(results) {
  var total = 0;
  for (var i = 0; i &lt; results.length; i++) {
    if (results[i].impact === 'critical') {
      total = total + 1;
    }
  }
  return total;
}

function showSummary(total) {
  var message = 'Critical failures: ' + total;
  console.log(message);
  return message;
}

var results = runChecks();
showSummary(countFailures(results));</code></pre>
</div>

3. Iframe

An iframe is treated as a group. These use srcdoc so they work without a network. Swap in a real video or map embed if you prefer.

Example 3.1: Embedded video

A video player inside an iframe with a title.

HTML markup 
<iframe title="Intro to screen readers video" srcdoc="&lt;!doctype html&gt;&lt;html lang=&quot;en&quot;&gt;&lt;body&gt;&lt;h1&gt;Intro to screen readers&lt;/h1&gt;&lt;p&gt;Video player (demo)&lt;/p&gt;&lt;button&gt;Play&lt;/button&gt; &lt;button&gt;Mute&lt;/button&gt; &lt;button&gt;Captions&lt;/button&gt;&lt;/body&gt;&lt;/html&gt;"></iframe>

4. ARIA widgets

Some composite widgets with ARIA roles may be treated as groups.

Example 4.1: Toolbar

A toolbar with three buttons.

HTML markup 
<div role="toolbar" aria-label="Text formatting">
  <button type="button">Bold</button>
  <button type="button">Italic</button>
  <button type="button">Underline</button>
</div>
