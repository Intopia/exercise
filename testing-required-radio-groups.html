Testing required on radio groups

A group of radio buttons can be a fieldset, a div with role="group", or a div with role="radiogroup". Only radiogroup supports aria-required. The examples below show what each technique does and does not do.

Simplest approach: for any group of checkboxes or radios, add the requirement to the group's name, or add it as a hint.

1. Requirement as text outside the group

Example 1.1: Text outside the group

A paragraph before the fieldset gives the requirement.

Required: Choose one pet.

Which is your favourite pet?

Poor practice: Nothing associates the paragraph with the group.

HTML markup 
<p>Required: Choose one pet.</p>
<fieldset>
  <legend>Which is your favourite pet?</legend>
  <div>
    <input type="radio" id="r7-dog" name="r7" value="dog">
    <label for="r7-dog">Dog</label>
  </div>
  <div>
    <input type="radio" id="r7-cat" name="r7" value="cat">
    <label for="r7-cat">Cat</label>
  </div>
  <div>
    <input type="radio" id="r7-rabbit" name="r7" value="rabbit">
    <label for="r7-rabbit">Rabbit</label>
  </div>
</fieldset>

2. aria-required on the container

Example 2.1: On the fieldset

aria-required="true" is added to the fieldset.

Which is your favourite pet?

Invalid: aria-required is not supported on the group role, which fieldset has implicitly.

HTML markup 
<fieldset aria-required="true">
  <legend>Which is your favourite pet?</legend>
  <div>
    <input type="radio" id="r11-dog" name="r11" value="dog">
    <label for="r11-dog">Dog</label>
  </div>
  <div>
    <input type="radio" id="r11-cat" name="r11" value="cat">
    <label for="r11-cat">Cat</label>
  </div>
  <div>
    <input type="radio" id="r11-rabbit" name="r11" value="rabbit">
    <label for="r11-rabbit">Rabbit</label>
  </div>
</fieldset>

Example 2.2: On the div with role="group"

aria-required="true" is added to the div with role="group".

Which is your favourite pet?

Invalid: aria-required is not supported on the group role.

HTML markup 
<div role="group" aria-labelledby="r12-label" aria-required="true">
  <p id="r12-label">Which is your favourite pet?</p>
  <div>
    <input type="radio" id="r12-dog" name="r12" value="dog">
    <label for="r12-dog">Dog</label>
  </div>
  <div>
    <input type="radio" id="r12-cat" name="r12" value="cat">
    <label for="r12-cat">Cat</label>
  </div>
  <div>
    <input type="radio" id="r12-rabbit" name="r12" value="rabbit">
    <label for="r12-rabbit">Rabbit</label>
  </div>
</div>

Example 2.3: On the div with role="radiogroup"

aria-required="true" is added to the div with role="radiogroup".

Which is your favourite pet?

Acceptable: radiogroup is the only group role that supports aria-required, so this exposes a required state to assistive technology. It adds nothing visible, so use it together with the group's name or a hint, not instead of them.

HTML markup 
<div role="radiogroup" aria-labelledby="r13-label" aria-required="true">
  <p id="r13-label">Which is your favourite pet?</p>
  <div>
    <input type="radio" id="r13-dog" name="r13" value="dog">
    <label for="r13-dog">Dog</label>
  </div>
  <div>
    <input type="radio" id="r13-cat" name="r13" value="cat">
    <label for="r13-cat">Cat</label>
  </div>
  <div>
    <input type="radio" id="r13-rabbit" name="r13" value="rabbit">
    <label for="r13-rabbit">Rabbit</label>
  </div>
</div>

4. Requirement on the radios

Example 4.1: aria-required on each radio

Every radio has aria-required="true".

Which is your favourite pet?

Invalid: aria-required is not supported on the radio role.

HTML markup 
<fieldset>
  <legend>Which is your favourite pet?</legend>
  <div>
    <input type="radio" id="r17-dog" name="r17" value="dog" aria-required="true">
    <label for="r17-dog">Dog</label>
  </div>
  <div>
    <input type="radio" id="r17-cat" name="r17" value="cat" aria-required="true">
    <label for="r17-cat">Cat</label>
  </div>
  <div>
    <input type="radio" id="r17-rabbit" name="r17" value="rabbit" aria-required="true">
    <label for="r17-rabbit">Rabbit</label>
  </div>
</fieldset>

Example 4.2: aria-required on one radio only

Only the first radio has aria-required="true".

Which is your favourite pet?

Invalid: aria-required is not supported on the radio role, and one radio does not set a requirement for the group.

HTML markup 
<fieldset>
  <legend>Which is your favourite pet?</legend>
  <div>
    <input type="radio" id="r18-dog" name="r18" value="dog" aria-required="true">
    <label for="r18-dog">Dog</label>
  </div>
  <div>
    <input type="radio" id="r18-cat" name="r18" value="cat">
    <label for="r18-cat">Cat</label>
  </div>
  <div>
    <input type="radio" id="r18-rabbit" name="r18" value="rabbit">
    <label for="r18-rabbit">Rabbit</label>
  </div>
</fieldset>

Example 4.3: required on every radio

Every radio has required.

Which is your favourite pet?

Poor practice: Native validation blocks submission until one radio is chosen. It relies on the browser's built-in message, which you can't word or style, and which only appears on submit.

HTML markup 
<fieldset>
  <legend>Which is your favourite pet?</legend>
  <div>
    <input type="radio" id="r19-dog" name="r19" value="dog" required>
    <label for="r19-dog">Dog</label>
  </div>
  <div>
    <input type="radio" id="r19-cat" name="r19" value="cat" required>
    <label for="r19-cat">Cat</label>
  </div>
  <div>
    <input type="radio" id="r19-rabbit" name="r19" value="rabbit" required>
    <label for="r19-rabbit">Rabbit</label>
  </div>
</fieldset>

Example 4.4: required on one radio only

Only the first radio has required.

Which is your favourite pet?

Poor practice: Native validation treats the whole named set as required, but the attribute is on one radio only, so users of assistive technology may take it to mean that one radio is required, not the group. It relies on the browser's built-in message, which you can't word or style, and which only appears on submit.

HTML markup 
<fieldset>
  <legend>Which is your favourite pet?</legend>
  <div>
    <input type="radio" id="r20-dog" name="r20" value="dog" required>
    <label for="r20-dog">Dog</label>
  </div>
  <div>
    <input type="radio" id="r20-cat" name="r20" value="cat">
    <label for="r20-cat">Cat</label>
  </div>
  <div>
    <input type="radio" id="r20-rabbit" name="r20" value="rabbit">
    <label for="r20-rabbit">Rabbit</label>
  </div>
</fieldset>

5. Requirement as text in the group's name

Example 5.1: fieldset

The legend includes (required).

Which is your favourite pet? (required)

Recommended: The requirement is in the group's accessible name, so it is available in text and associated with the group (WCAG 1.3.1 and 3.3.2). It does not expose a required state to assistive technology.

HTML markup 
<fieldset>
  <legend>Which is your favourite pet? (required)</legend>
  <div>
    <input type="radio" id="r4-dog" name="r4" value="dog">
    <label for="r4-dog">Dog</label>
  </div>
  <div>
    <input type="radio" id="r4-cat" name="r4" value="cat">
    <label for="r4-cat">Cat</label>
  </div>
  <div>

  </div>
</fieldset>

6. Requirement as a hint

Example 6.1: fieldset

A hint paragraph inside the group is linked to it with aria-describedby.

Which is your favourite pet?

Choose one pet.

Recommended: The hint is associated with the group with aria-describedby, so the requirement is available in text (WCAG 1.3.1 and 3.3.2). It does not expose a required state to assistive technology.

HTML markup 
<fieldset aria-describedby="r8-hint">
  <legend>Which is your favourite pet?</legend>
  <p id="r8-hint">Choose one pet.</p>
  <div>
    <input type="radio" id="r8-dog" name="r8" value="dog">
    <label for="r8-dog">Dog</label>
  </div>
  <div>
    <input type="radio" id="r8-cat" name="r8" value="cat">
