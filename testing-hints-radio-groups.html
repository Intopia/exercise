Testing hints on radio groups

Hints for a group of radios need to be programmatically associated with the group, not just placed near it. Every example is pre-set in the markup, so no JavaScript is needed.

Simplest approach: link the hint to the group with aria-describedby. See the recommended examples.

Every example has a coloured box below it showing how to read it:

Poor practice: allowed, but not recommended.

Acceptable: allowed, and does part of the job. The box says what it does and does not give you.

Recommended: the approach to use.

1. Text with no association

The hint is visible, but nothing links it to the group.

Example 1.1: Hint, not linked

A fieldset with the hint in a paragraph inside it.

Which is your favourite pet?

Choose one pet.

Poor practice: Nothing associates the hint with the group, so assistive technology users may not hear it.

HTML markup 
<fieldset>
  <legend>Which is your favourite pet?</legend>
  <p>Choose one pet.</p>
  <div>
    <input type="radio" id="r1-dog" name="r1" value="dog">
    <label for="r1-dog">Dog</label>
  </div>
  <div>
    <input type="radio" id="r1-cat" name="r1" value="cat">
    <label for="r1-cat">Cat</label>
  </div>
  <div>
    <input type="radio" id="r1-rabbit" name="r1" value="rabbit">
    <label for="r1-rabbit">Rabbit</label>
  </div>
</fieldset>

2. Hint as text in the group's name

The hint is written into the group's name: the legend, or the labelling element.

Example 2.1: fieldset

The hint is added to the group's name.

Which is your favourite pet? (choose one)

Acceptable: The hint is part of the group's accessible name, so it is announced when users enter the group. It makes the name longer, and linking the hint with aria-describedby keeps the name short.

HTML markup 
<fieldset>
  <legend>Which is your favourite pet? (choose one)</legend>
  <div>
    <input type="radio" id="r2-dog" name="r2" value="dog">
    <label for="r2-dog">Dog</label>
  </div>

    <input type="radio" id="r2-rabbit" name="r2" value="rabbit">
    <label for="r2-rabbit">Rabbit</label>
  </div>
</fieldset>

3. aria-describedby on the radios

The hint is linked to the radios themselves.

Example 3.1: aria-describedby on each radio

Every radio has aria-describedby pointing to the hint.

Which is your favourite pet?

Choose one pet.

Poor practice: The hint is repeated on every radio, and it is not associated with the group itself.

HTML markup 
<fieldset>
  <legend>Which is your favourite pet?</legend>
  <p id="r5-hint">Choose one pet.</p>
  <div>
    <input type="radio" id="r5-dog" name="r5" value="dog" aria-describedby="r5-hint">
    <label for="r5-dog">Dog</label>
  </div>
  <div>
    <input type="radio" id="r5-cat" name="r5" value="cat" aria-describedby="r5-hint">
    <label for="r5-cat">Cat</label>
  </div>
  <div>
    <input type="radio" id="r5-rabbit" name="r5" value="rabbit" aria-describedby="r5-hint">
    <label for="r5-rabbit">Rabbit</label>
  </div>
</fieldset>

Example 3.2: aria-describedby on one radio only

Only the first radio has aria-describedby pointing to the hint.

Which is your favourite pet?

Choose one pet.

Poor practice: Only that radio has the hint description, so users may think it applies to that radio only, not the group.

HTML markup 
<fieldset>
  <legend>Which is your favourite pet?</legend>
  <p id="r6-hint">Choose one pet.</p>
  <div>
    <input type="radio" id="r6-dog" name="r6" value="dog" aria-describedby="r6-hint">
    <label for="r6-dog">Dog</label>
  </div>
  <div>
    <input type="radio" id="r6-cat" name="r6" value="cat">
    <label for="r6-cat">Cat</label>
  </div>
  <div>
    <input type="radio" id="r6-rabbit" name="r6" value="rabbit">
    <label for="r6-rabbit">Rabbit</label>
  </div>
</fieldset>

None of these options is good practice.

4. Hint linked to the group

The hint is linked to the group with aria-describedby.

Example 4.1: fieldset

The group has aria-describedby pointing to the hint.

Which is your favourite pet?

Choose one pet.

Recommended: The hint is associated with the group with aria-describedby, so assistive technology can announce it as the group's description.

HTML markup 
<fieldset aria-describedby="r7-hint">
  <legend>Which is your favourite pet?</legend>
  <p id="r7-hint">Choose one pet.</p>
  <div>
    <input type="radio" id="r7-dog" name="r7" value="dog">
    <label for="r7-dog">Dog</label>
  </div>
  <div>
    <input type="radio" id="r7-cat" name="r7" value="cat">

  </div>
  <div>
    <input type="radio" id="r7-rabbit" name="r7" value="rabbit">
    <label for="r7-rabbit">Rabbit</label>
  </div>
</fieldset>

Using hints and errors together

A group can have both a hint and an error. Hints and errors use the same method, so list both IDs in one aria-describedby, separated by a space. See Testing errors on radio groups.

<fieldset aria-describedby="pets-hint pets-error">
  <legend>Which is your favourite pet?</legend>
  <p id="pets-hint">Choose the pet you like best.</p>
  <p id="pets-error">Error: Choose one pet.</p>
  <!-- radio inputs and labels -->
</fieldset>
