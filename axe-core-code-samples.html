axe-core code samples for the browser console

Copy and paste these samples into the browser console, in order, on the page you want to test. Samples 1 to 3 set things up. Samples 4 to 11 explore the results. Sample 12 combines loading and reporting into one snippet.

1. Load axe-core into the page

Adds a script element that pulls axe-core from a CDN. Wait a second or two for it to finish loading before moving on.

var script = document.createElement('script');
script.src =
  'https://cdn.jsdelivr.net/npm/axe-core@4.14.0/axe.min.js';
document.head.appendChild(script);

Expected result: Nothing is printed, or the console shows the script element. If a page blocks external scripts (a Content Security Policy), the load will fail. Try a different page.

2. Check axe has loaded

Asks axe-core which version it is.

axe.version

Expected result: The console prints the version number, '4.14.0'. If axe has not loaded, it prints ReferenceError: axe is not defined. Wait a moment and try again.

3. Run axe

Tests the page and stores everything axe finds in a variable called results.

var results = await axe.run();

Expected result: The console prints undefined. That's normal. The results have been stored in results, ready for the next samples.

4. Count each list

The results object holds four lists. Check how many items are in each.

console.log('violations:', results.violations.length);
console.log('passes:', results.passes.length);
console.log('incomplete:', results.incomplete.length);
console.log('inapplicable:', results.inapplicable.length);

What each list holds

  • violations: rules that failed
  • passes: rules that passed
  • incomplete: items axe could not decide, which need a manual check
  • inapplicable: rules with nothing on the page to test

Expected result: Four lines, each with a list name and a count.

5. Look at the first failed rule

Prints the first item in the violations list, so you can see what a single result looks like.

console.log(results.violations[0]);

Expected result: The console prints an object. Expand it to see the rule's id, impact, help text and the nodes (elements) that failed.

6. Count the failed rules

One number: how many rules failed.

results.violations.length

Expected result: The console prints a number. This counts failed rules, not failed elements. One rule can fail on many elements.

7. Show the violations as a table

One row per failed rule, with the rule name, how severe it is and how many elements failed.

console.table(
  results.violations.map(v => ({
    rule: v.id,
    impact: v.impact,
    elements: v.nodes.length
  }))
);

Expected result: The console prints a table with the columns rule, impact and elements.

8. Filter to critical and serious

Keeps only the most severe failures, then shows them as a table.

var important = results.violations.filter(v =>
  v.impact === 'critical' || v.impact === 'serious'
);

console.table(
  important.map(v => ({
    rule: v.id,
    impact: v.impact,
    elements: v.nodes.length
  }))
);

Expected result: The table only lists rules with an impact of critical or serious. The other levels are moderate and minor.

9. See which elements failed

Lists each failed rule, then a selector for every element that failed it.

results.violations.forEach(v => {
  console.log(v.id);
  v.nodes.forEach(n => {
    console.log('  ', n.target.join(' '));
  });
});

Expected result: Each rule name is followed by an indented list of CSS selectors, one per failing element.

10. Highlight the failing elements

Draws a red outline around every element that failed.

results.violations.forEach(v => {
  v.nodes.forEach(n => {
    var el = document.querySelector(n.target[0]);
    if (el) {
      el.style.outline = '4px solid red';
    }
  });
});

Expected result: Failing elements get a red outline on the page. Refresh the page to remove the outlines. This simple version may miss elements inside iframes or shadow DOM.

11. Show fixes

Prints each failed rule with its plain-language help text, a link to the full rule description, and what to change on each failing element.

results.violations.forEach(v => {
  console.log(v.help);
  console.log(v.helpUrl);
  v.nodes.forEach(n => {
    console.log(n.target.join(' '));
    console.log(n.failureSummary);
  });
});

Expected result: Each failing element is followed by text starting with Fix any of the following: or Fix all of the following:, then the specific changes needed.

12. Load axe and show the table in one snippet

Everything needed in a single copy and paste: load axe-core if it isn't already on the page, run it, and show the results. It's safe to paste more than once.

(async () => {
  if (!window.axe) {
    const script = document.createElement('script');
    script.src = 'https://cdn.jsdelivr.net/npm/axe-core@4.14.0/axe.min.js';
    const loaded = new Promise((resolve, reject) => {
      script.onload = resolve;
      script.onerror = () => reject(new Error('axe-core failed to load (check CSP or version)'));
    });
    document.head.appendChild(script);
    await loaded;
  }
  const results = await axe.run();
  window.results = results;
  console.log(`${results.violations.length} violations`);
  console.table(results.violations.map(v => ({ id: v.id, impact: v.impact, nodes: v.nodes.length })));
  console.log(results);
})();

Expected result: After a short pause, the console prints the number of violations, a table of the failed rules, then the full results object. If axe-core can't load, you'll see the error axe-core failed to load (check CSP or version). The results variable is still available, so samples 4 to 11 will also work.
