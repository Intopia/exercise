Testing text styles

Run the Inspect text styles bookmarklet, then click any sample. A panel should report the styles that apply to the element you clicked. Press Esc to stop.

Each sample has a small grey label above it showing the CSS used and the values you should expect in the panel. Click the sample text, not the label.

The panel rows are: Font, Size, Weight, Style, Line height, Letter sp., Word sp. and Colour. Background colour is not reported.
