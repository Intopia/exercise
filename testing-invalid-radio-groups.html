Testing aria-invalid on radio groups

When a group of radios is in error, assistive technology needs to be told that the group is invalid. The examples below test how to expose that invalid state. Every state is pre-set in the markup, so no JavaScript is needed. The same visible error text is in every example, and nothing links it to the group, so the examples test the invalid state only.

Simplest approach: add aria-invalid="true" to a div with role="radiogroup". See the recommended example.

Every example has a coloured box below it showing how to read it:

Poor practice: allowed, but not recommended.

Recommended: the approach to use.

1. aria-invalid on the radios

aria-invalid on the radios themselves.

Example 1.1: aria-invalid on each radio

Every radio has aria-invalid="true".

Which is your favourite pet?

Error: Choose one pet.

Poor practice: aria-invalid is deprecated as a global attribute in ARIA 1.2 and is not supported on the radio role. Every radio is marked invalid.

HTML markup 
<fieldset>
  <legend>Which is your favourite pet?</legend>
  <p class="error">Error: Choose one pet.</p>
  <div>
    <input type="radio" id="r1-dog" name="r1" value="dog" aria-invalid="true">
    <label for="r1-dog">Dog</label>
  </div>
  <div>
    <input type="radio" id="r1-cat" name="r1" value="cat" aria-invalid="true">
    <label for="r1-cat">Cat</label>
  </div>
  <div>
    <input type="radio" id="r1-rabbit" name="r1" value="rabbit" aria-invalid="true">
    <label for="r1-rabbit">Rabbit</label>
  </div>
</fieldset>

Example 1.2: aria-invalid on one radio only

Only the first radio has aria-invalid="true".

Which is your favourite pet?

Error: Choose one pet.

Poor practice: aria-invalid is not supported on the radio role. Only that radio is marked invalid, so users may think only that radio is in error.

HTML markup 
<fieldset>
  <legend>Which is your favourite pet?</legend>
  <p class="error">Error: Choose one pet.</p>
  <div>
    <input type="radio" id="r2-dog" name="r2" value="dog" aria-invalid="true">
    <label for="r2-dog">Dog</label>
  </div>
  <div>
    <input type="radio" id="r2-cat" name="r2" value="cat">
    <label for="r2-cat">Cat</label>
  </div>
  <div>
    <input type="radio" id="r2-rabbit" name="r2" value="rabbit">
    <label for="r2-rabbit">Rabbit</label>
  </div>
</fieldset>

None of these options is good practice.

2. aria-invalid on the group

aria-invalid marks the group as being in error. It is supported on radiogroup, not on the group role.

Example 2.1: fieldset

aria-invalid="true" is added to the group.

Which is your favourite pet?

Error: Choose one pet.

Poor practice: aria-invalid is deprecated as a global attribute in ARIA 1.2 and is not supported on the group role.

HTML markup 
<fieldset aria-invalid="true">
  <legend>Which is your favourite pet?</legend>
  <p class="error">Error: Choose one pet.</p>
  <div>
    <input type="radio" id="r3-dog" name="r3" value="dog">
    <label for="r3-dog">Dog</label>
  </div>
  <div>
    <input type="radio" id="r3-cat" name="r3" value="cat">
    <label for="r3-cat">Cat</label>
  </div>
  <div>
    <input type="radio" id="r3-rabbit" name="r3" value="rabbit">
    <label for="r3-rabbit">Rabbit</label>
  </div>
</fieldset>

Example 2.2: div with role="group"

aria-invalid="true" is added to the group.

Which is your favourite pet?

Error: Choose one pet.

Poor practice: aria-invalid is deprecated as a global attribute in ARIA 1.2 and is not supported on the group role.

HTML markup 
<div role="group" aria-labelledby="r4-label" aria-invalid="true">
  <h4 id="r4-label">Which is your favourite pet?</h4>
  <p class="error">Error: Choose one pet.</p>
  <div>
    <input type="radio" id="r4-dog" name="r4" value="dog">
    <label for="r4-dog">Dog</label>
  </div>
  <div>
    <input type="radio" id="r4-cat" name="r4" value="cat">
    <label for="r4-cat">Cat</label>
  </div>
  <div>
    <input type="radio" id="r4-rabbit" name="r4" value="rabbit">
    <label for="r4-rabbit">Rabbit</label>
  </div>
</div>

Example 2.3: div with role="radiogroup"

aria-invalid="true" is added to the group.

Which is your favourite pet?

Error: Choose one pet.

Recommended: aria-invalid is supported on radiogroup, so the group exposes an invalid state.

HTML markup 
<div role="radiogroup" aria-labelledby="r5-label" aria-invalid="true">
  <h4 id="r5-label">Which is your favourite pet?</h4>
  <p class="error">Error: Choose one pet.</p>
  <div>
    <input type="radio" id="r5-dog" name="r5" value="dog">
    <label for="r5-dog">Dog</label>
  </div>
  <div>
    <input type="radio" id="r5-cat" name="r5" value="cat">
    <label for="r5-cat">Cat</label>
  </div>
  <div>
    <input type="radio" id="r5-rabbit" name="r5" value="rabbit">
    <label for="r5-rabbit">Rabbit</label>
  </div>
</div>
