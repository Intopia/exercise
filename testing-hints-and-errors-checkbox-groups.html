Testing hints and errors on checkbox groups

Hints and error messages for a group of checkboxes need to be programmatically associated with the group, not just placed near it. Hints and errors use the same method, so they are tested together. Every example is pre-set in the markup, so no JavaScript is needed.

Simplest approach: link the hint or error to the group with aria-describedby. See Recommended practice.

Every example has a coloured box showing how to read it:

Poor practice: allowed, but not recommended.

Acceptable: allowed, and does part or all of the job. The box says what it does and does not give you.

Control: a baseline.

1. Controls

Baselines with no hint or error shown.

Example 1.1: fieldset

Control: A group with no hint or error shown.

Which pets do you have?
HTML markup 
<fieldset>
  <legend>Which pets do you have?</legend>
  <div>
    <input type="checkbox" id="c1-dog" name="c1" value="dog">
    <label for="c1-dog">Dog</label>
  </div>
  <div>
    <input type="checkbox" id="c1-cat" name="c1" value="cat">
    <label for="c1-cat">Cat</label>
  </div>
  <div>
    <input type="checkbox" id="c1-rabbit" name="c1" value="rabbit">
    <label for="c1-rabbit">Rabbit</label>
  </div>
</fieldset>

2. Text with no association

The hint or error is visible, but nothing links it to the group.

None of these options is good practice.

Example 2.1: Hint, not linked

Poor practice: The hint is in a paragraph inside the group. Nothing associates it with the group, so assistive technology users may not hear it.

Which pets do you have?

3. Error as text in the group's name

The error message is written into the group's name: the legend, or the labelling element.

None of these options is good practice.

Example 3.1: fieldset

Poor practice: The error is part of the group's accessible name, so it is announced when users enter the group. But it makes the name longer and changes it whenever there is an error. Prefer aria-describedby.

Which pets do you have? Error: Choose at least one pet.

<fieldset>
  <legend>Which pets do you have? <span class="error">Error: Choose at least one pet.</span></legend>

4. Hint linked to the group

The hint is linked to the group with aria-describedby.

Example 4.1: fieldset

Acceptable: The hint is associated with the group with aria-describedby, so assistive technology can announce it as the group's description.

Choose at least one pet.

7. aria-describedby on the checkboxes

The hint or error is linked to the checkboxes themselves.

None of these options is good practice.

Example 7.1: aria-describedby on each checkbox

Poor practice: The error is repeated on every checkbox, and it is not associated with the group itself.

Which pets do you have?

Error: Choose at least one pet.

HTML markup 
<fieldset>
  <legend>Which pets do you have?</legend>
  <p class="error" id="c13-error">Error: Choose at least one pet.</p>
  <div>
    <input type="checkbox" id="c13-dog" name="c13" value="dog" aria-describedby="c13-error">
    <label for="c13-dog">Dog</label>
  </div>
  <div>
    <input type="checkbox" id="c13-cat" name="c13" value="cat" aria-describedby="c13-error">
    <label for="c13-cat">Cat</label>
  </div>
  <div>
    <input type="checkbox" id="c13-rabbit" name="c13" value="rabbit" aria-describedby="c13-error">
    <label for="c13-rabbit">Rabbit</label>
  </div>
</fieldset>
