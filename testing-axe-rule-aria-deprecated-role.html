Testing the axe rule aria-deprecated-role

Test cases for the axe-core rule aria-deprecated-role (axe-core 4.14). Some roles have been removed from ARIA, or are being phased out. They may still work, but support is likely to drop away. Axe 4.14 treats three roles as deprecated:

Deprecated roles in axe-core 4.14
RoleUse instead
directorylist
doc-biblioentrylistitem (inside doc-bibliography)
doc-endnotelistitem (inside doc-endnotes)

With a list of roles, axe checks the first valid one. Deprecated roles are still valid roles, so aria-roles doesn't flag them.

Each case also shows the axe message key and which Intopia issue template the result would go to under the current assembly rules. Results on this page were checked in Chrome.

axe-core results: See the HTML report from running axe-core 4.14.0 over this page.

Every example is live in the page, so you can run the axe extension straight over it. The expected results were checked by running axe-core 4.14.1 over this page. Look in both the axe issues list and the needs review list.

Deprecated roles

These fail with "The role used is deprecated".

A1 role="directory"

Deprecated in ARIA 1.2. Use list, or just a <ul>.

Staff list: Alex, Sam, Priya
<div role="directory">Staff list: Alex, Sam, Priya</div>

Expected result: fail

Template routing: Message key: none. Routes to: NEW-32, which wasn't in this review.

A2 role="DIRECTORY" in capitals

Office locations
<div role="DIRECTORY">Office locations</div>

Expected result: fail

Template routing: Message key: none. Routes to: NEW-32, which wasn't in this review.

A3 role="doc-endnote"

The container role doc-endnotes is fine. Only the item role is deprecated.

  1. First published in 2019.
<section role="doc-endnotes" aria-label="Notes">
  <ol>
    <li role="doc-endnote">First published in 2019.</li>
  </ol>
</section>

Expected result: fail

Template routing: Message key: none. Routes to: NEW-32, which wasn't in this review.

A4 role="doc-biblioentry"

  1. Smith, J. (2024). Accessible forms.
<section role="doc-bibliography" aria-label="References">
  <ol>
    <li role="doc-biblioentry">Smith, J. (2024). Accessible forms.</li>
  </ol>
</section>

Expected result: fail

Template routing: Message key: none. Routes to: NEW-32, which wasn't in this review.

A5 A deprecated role first in a list

Axe checks the first valid role, which is directory.

Sales, Support
<div role="directory group" aria-label="Teams">Sales, Support</div>

Expected result: fail

Template routing: Message key: none. Routes to: NEW-32, which wasn't in this review.

A6 An invalid role, then a deprecated one

The invalid role is skipped, so the first valid role is directory.

Departments
<div role="drectory directory">Departments</div>

Expected result: fail

Template routing: Message key: none. Routes to: NEW-32, which wasn't in this review.
