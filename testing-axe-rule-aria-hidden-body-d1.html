Testing the axe rule aria-hidden-body: D1

D1 Dialog script that hides the body

On load, the body is fine. The button opens a dialog and adds aria-hidden="true" to the body to hide the page behind it, an older pattern. The dialog is inside the body, so in browsers that honour the attribute it would be hidden too. Open the dialog, then run axe.

<body>
  ...
  <button type="button" id="d1-open">Open dialog</button>
  <div role="dialog" id="d1-dialog" aria-labelledby="d1-title" hidden>
    <h2 id="d1-title">Delete file</h2>
    <p>This can't be undone.</p>
    <button type="button" id="d1-close">Cancel</button>
  </div>
</body>

On load: pass. After opening: fail

After opening, this rule fails and routes to NEW-47. aria-hidden-focus and bypass ask for review. Unlike A1, landmark-one-main and page-has-heading-one don't fail.
