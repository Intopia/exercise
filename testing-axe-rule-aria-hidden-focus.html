Testing the axe rule aria-hidden-focus

Test cases for the axe-core rule aria-hidden-focus (axe-core 4.14). aria-hidden="true" hides content from screen readers. If something inside it can still be reached with the Tab key, keyboard users land on something a screen reader won't announce.

The rule only counts content in the Tab order. It runs three checks:

  • focusable-disabled: buttons and form controls that can still be reached with Tab.
  • focusable-not-tabbable: links and anything else that can still be reached with Tab.
  • focusable-modal-open: if a dialog is open anywhere on the page, every failure from this rule becomes needs review instead. See G2.

The rule only tests the outermost element with aria-hidden="true". aria-hidden on the <body> is checked by a different rule, aria-hidden-body.

Results on this page were checked in Chrome.

axe-core results: See the HTML report from running axe-core 4.14.0 over this page.

Every example is live in the page, so you can run the axe extension straight over it. The expected results were checked by running axe-core 4.14.1 over this page. Look in both the axe issues list and the needs review list.

Links and other content that can still be reached

These fail with "Focusable content should have tabindex="-1", be removed from the DOM, or not be hidden with aria-hidden".

A1 A link inside aria-hidden

A closed menu hidden with aria-hidden, but its link still in the Tab order.

  • My orders
<ul class="menu" aria-hidden="true">
  <li><a href="#a1">My orders</a></li>
</ul>

Expected result: fail

Template routing: Check: focusable-not-tabbable. Routes to: NEW-48.

</div>

Ways to pass

Control cases. These show the right ways to hide content that can receive focus.

E1 tabindex="-1" on the link

My orders 
<div aria-hidden="true">
  <a href="#e1" tabindex="-1">My orders</a>
</div>

Expected result: pass (valid)

E2 A disabled button

<div aria-hidden="true">
  <button type="button" disabled>Close</button>
</div>

Expected result: pass (valid)

E3 A disabled fieldset

Disabling the fieldset disables everything inside it.

Delivery 
<div aria-hidden="true">
  <fieldset disabled>
    <legend>Delivery</legend>
    <input type="text" aria-label="Postcode">
  </fieldset>
</div>

Expected result: pass (valid)

E4 The inert attribute

inert takes everything inside out of the Tab order.

Wish list 
<div aria-hidden="true" inert>
  <a href="#e4">Wish list</a>
</div>

Expected result: pass (valid)

E5 A link hidden with display: none

Returns 
<div aria-hidden="true">
  <a href="#e5" style="display: none;">Returns</a>
</div>

Expected result: pass (valid)

E6 A link hidden with visibility: hidden

Contact 
<div aria-hidden="true">
  <a href="#e6" style="visibility: hidden;">Contact</a>
</div>

Expected result: pass (valid)

E7 A duplicate icon link

A common pattern: the image link is hidden and taken out of the Tab order, because the text link next to it goes to the same place.

Blue kettle 
<a href="#e7" aria-hidden="true" tabindex="-1"><img src="data:image/gif;base64,R0lGODlhAQABAAAAACw=" alt="" width="20" height="20"></a>
<a href="#e7">Blue kettle</a>

Expected result: pass (valid)

Changes after interaction

Axe only sees the page as it is when you run it. These pass on page load. Activate each button, then run axe again.

G1 A menu that's closed with aria-hidden

The menu starts open. Closing it sets aria-hidden="true", but its links stay in the Tab order.

  • Home
  • Shop
<button type="button" id="g1-button" aria-expanded="true" aria-controls="g1-menu">Close menu</button>
<ul id="g1-menu">
  <li><a href="#g1">Home</a></li>
  <li><a href="#g1">Shop</a></li>
</ul>

On load: pass. After closing: fail

After closing, the check is focusable-not-tabbable, so it routes to NEW-48.

G2 Opening a dialog changes the whole page

While a dialog is open, axe assumes the content behind it may be hidden on purpose. Open this dialog, then run axe again: every failure from this rule on the page becomes needs review.

Sign up for our newsletter.

<button type="button" id="g2-button">Open dialog</button>
<div role="dialog" id="g2-dialog" aria-label="Newsletter" hidden>
  <p>Sign up for our newsletter.</p>
</div>

After opening: every fail on this page becomes needs review

After opening, the check is focusable-modal-open, so every result routes to no template. Reload the page to close the dialog.
