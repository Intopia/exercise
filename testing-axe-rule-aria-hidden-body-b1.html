Testing the axe rule aria-hidden-body: B1

B1 aria-hidden="true" on the html element

The rule only looks at <body>, so this passes. Chrome ignores it here too.

<html lang="en" aria-hidden="true">
  ...
  <body>
    ...
  </body>
</html>

Expected result: flagged by aria-hidden-focus instead

aria-hidden-focus fails the <html> element, because the links inside it can receive focus.

Template routing: Routes to: NEW-48, not NEW-47.

This page has some plain content so there's something to hide: a heading, this paragraph, and the links back to the other cases.
