Testing aria-invalid on checkbox groups

When a group of checkboxes is in error, assistive technology needs to be told that the group is invalid. The examples below test how to expose that invalid state. Every state is pre-set in the markup, so no JavaScript is needed. The same visible error text is in every example, and nothing links it to the group, so the examples test the invalid state only.

Simplest approach: add aria-invalid="true" to each checkbox. See the recommended example.

1. aria-invalid on the group

Example 1.1: fieldset

aria-invalid="true" is added to the group.

Which pets do you have?

Error: Choose at least one pet.

Poor practice: The group role does not support aria-invalid.

HTML markup 
<fieldset aria-invalid="true">
  <legend>Which pets do you have?</legend>
  <p class="error">Error: Choose at least one pet.</p>
  <div>
    <input type="checkbox" id="c1-dog" name="c1" value="dog">
    <label for="c1-dog">Dog</label>
  </div>
  <div>
    <input type="checkbox" id="c1-cat" name="c1" value="cat">
    <label for="c1-cat">Cat</label>
  </div>
  <div>
    <input type="checkbox" id="c1-rabbit" name="c1" value="rabbit">
    <label for="c1-rabbit">Rabbit</label>
  </div>
</fieldset>

Example 1.2: div with role="group"

aria-invalid="true" is added to the group.

Which pets do you have?

Error: Choose at least one pet.

Poor practice: The group role does not support aria-invalid.

HTML markup 
<div role="group" aria-labelledby="c2-label" aria-invalid="true">
  <h4 id="c2-label">Which pets do you have?</h4>
  <p class="error">Error: Choose at least one pet.</p>
  <div>
    <input type="checkbox" id="c2-dog" name="c2" value="dog">
    <label for="c2-dog">Dog</label>
  </div>
  <div>
    <input type="checkbox" id="c2-cat" name="c2" value="cat">
    <label for="c2-cat">Cat</label>
  </div>
  <div>
    <input type="checkbox" id="c2-rabbit" name="c2" value="rabbit">
    <label for="c2-rabbit">Rabbit</label>
  </div>
</div>

None of these options is good practice.

2. aria-invalid on the checkboxes

Example 2.1: aria-invalid on one checkbox only

Only the first checkbox has aria-invalid="true".

Which pets do you have?

Error: Choose at least one pet.

Poor practice: Only that checkbox is marked invalid, so users may think only that checkbox is in error, when the error is about the group.

HTML markup 
<fieldset>
  <legend>Which pets do you have?</legend>
  <p class="error">Error: Choose at least one pet.</p>
  <div>
    <input type="checkbox" id="c3-dog" name="c3" value="dog" aria-invalid="true">
    <label for="c3-dog">Dog</label>
  </div>
  <div>
    <input type="checkbox" id="c3-cat" name="c3" value="cat">
    <label for="c3-cat">Cat</label>
  </div>
  <div>
    <input type="checkbox" id="c3-rabbit" name="c3" value="rabbit">
    <label for="c3-rabbit">Rabbit</label>
  </div>
</fieldset>

Example 2.2: aria-invalid on each checkbox

Every checkbox has aria-invalid="true".

Which pets do you have?

Error: Choose at least one pet.

Recommended: aria-invalid is supported on checkbox, so each checkbox exposes an invalid state.

HTML markup 
<fieldset>
  <legend>Which pets do you have?</legend>
  <p class="error">Error: Choose at least one pet.</p>
  <div>
    <input type="checkbox" id="c4-dog" name="c4" value="dog" aria-invalid="true">
    <label for="c4-dog">Dog</label>
  </div>
  <div>
    <input type="checkbox" id="c4-cat" name="c4" value="cat" aria-invalid="true">
    <label for="c4-cat">Cat</label>
  </div>
  <div>
    <input type="checkbox" id="c4-rabbit" name="c4" value="rabbit" aria-invalid="true">
    <label for="c4-rabbit">Rabbit</label>
  </div>
</fieldset>
