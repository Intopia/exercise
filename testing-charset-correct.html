Testing character encoding: correct example

<meta charset="utf-8"> is the first element inside <head> and matches the file's encoding. Incorrect encoding can cause text to display incorrectly and affect what screen readers announce.

The example below uses special characters rather than HTML entities to help identify encoding problems.

Café — naïve piñata costs €5.99, “today” only.

Expected result: every character above, accented letters, the em dash, the euro sign, and the curly quotes, should render exactly as authored, both visually and when read by assistive technology.

HTML markup 
<head>
  <meta charset="utf-8">
  ...
</head>
