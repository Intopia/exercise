Testing aria-pressed

aria-pressed indicates the current state of a toggle button. It supports true, false and mixed. It can be used on a native <button> or an element with role="button".

This page uses a set of server controls to demonstrate all three states, including how mixed can represent a group of controls with different states.

Example: servers

This example has four buttons. The "All servers" button controls the three individual server buttons. Its aria-pressed state changes automatically based on their states:

  • All off: aria-pressed="false", "Turn all servers on".
  • All on: aria-pressed="true", "Turn all servers off".
  • Mixed: aria-pressed="mixed", "Turn all servers off".

There is no aria-live region. Screen readers may announce changes to a button's state or label while it has focus, or when focus returns to it.

Try this:

  1. Turn on a screen reader and Tab to "All servers". It should announce as "not pressed".
  2. Tab to Server 2 and activate it. Then use Shift+Tab to return to "All servers". It should announce as "mixed".
  3. Activate the remaining servers, then return to "All servers". It should announce as "pressed".
  4. Activate "All servers" to turn everything off. It should announce as "not pressed".
HTML markup 
<button id="all-servers" aria-pressed="false">
  Turn all servers on
</button>
<button id="server-1" data-name="Server 1" aria-pressed="false">
  Turn Server 1 on
</button>
<!-- Server 2 and Server 3 follow the same pattern -->
JavaScript 
const allServers = document.getElementById('all-servers');
const serverButtons = Array.from(document.querySelectorAll('.server-button'));

function serverLabel(name, isPressed) {
  return isPressed ? `Turn ${name} off` : `Turn ${name} on`;
}

function updateAllServers() {
  const states = serverButtons.map(btn => btn.getAttribute('aria-pressed'));
  const allOn = states.every(state => state === 'true');
  const allOff = states.every(state => state === 'false');

  if (allOff) {
    allServers.setAttribute('aria-pressed', 'false');
    allServers.textContent = 'Turn all servers on';
  } else if (allOn) {
    allServers.setAttribute('aria-pressed', 'true');
    allServers.textContent = 'Turn all servers off';
  } else {
    // Mixed and all-on share the same label, turning off is always
    // the offered action unless every server is already off.
    // Colour, not text, is what distinguishes mixed from all-on here.
    allServers.setAttribute('aria-pressed', 'mixed');
    allServers.textContent = 'Turn all servers off';
  }
}

serverButtons.forEach(btn => {
  btn.addEventListener('click', () => {
    const isPressed = btn.getAttribute('aria-pressed') === 'true';
    const nextPressed = !isPressed;
    btn.setAttribute('aria-pressed', String(nextPressed));
    btn.textContent = serverLabel(btn.dataset.name, nextPressed);
    updateAllServers();
  });
});

allServers.addEventListener('click', () => {
  const currentState = allServers.getAttribute('aria-pressed');
  // Only turn everything on if every server is currently off.
  // Otherwise (true or mixed), the action is always to turn everything off.
  const turnOn = currentState === 'false';

  serverButtons.forEach(btn => {
    btn.setAttribute('aria-pressed', String(turnOn));
    btn.textContent = serverLabel(btn.dataset.name, turnOn);
  });

  updateAllServers();
});

Design notes

  • Button labels: The buttons use action-based labels such as "Turn Server 1 off". For toggle buttons using aria-pressed, a consistent label such as "Server 1" is generally recommended.
  • Mixed state: The "All servers" button uses aria-pressed="mixed" when some servers are on and others are off.
  • Colour: Different colours help show the states, but colour should not be the only way to distinguish them.

Note for testing: confirm the mixed state announcement, and that "mixed" and "all on" are correctly distinguished by colour when they share the same button text, with your standard browser and screen reader combinations before treating them as settled.
